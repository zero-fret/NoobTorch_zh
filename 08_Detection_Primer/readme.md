# 08 — 检测入门（不训练）
分类输出一个类别标签。检测还要说出每个物体在**哪里**。在构建 YOLO 之前，先手动学会它的输出词汇。

## 核心概念
检测器把"10 个类别分数"替换为一个**边界框**列表，每个框带置信度和（可选的）类别。本节课的其他所有内容都只是为了产生、解码和评判这些框。

## 1. 框格式
- **YOLO 标签**：`(cx, cy, w, h)` 归一化到 [0,1]——图像的比例。
- **像素 `xyxy`**：`(x1, y1, x2, y2)`，左上角和右下角——用于绘图和 IoU。
`boxes.py` 在它们之间转换。

## 2. IoU（交并比）
`IoU = 交集面积 / 并集面积`，两个框之间。1.0 = 完全相同，0 = 不重叠。这是判断"这个框对不对"的唯一数字。

## 3. 网格
简易 YOLO 将图像分成 `S × S` 网格。物体中心所在的网格单元负责该物体：
- `(gx, gy)` = 负责单元；
- `(tx, ty)` = 中心在该单元内的偏移；
- `(tw, th)` = 框大小；
- `conf` = 置信度（这个单元里到底有没有物体？）。
网络输出 `(5, S, S)`——每个单元一个框。`demo.py` 展示标签如何变成网格单元和偏移。

## 4. 置信度与 sigmoid
原始网络 logit 可以是任何数；`sigmoid` 把它映射到 (0,1)。置信度是 sigmoid；框偏移/大小也用 sigmoid 限制在合法范围。

## 5. 置信度阈值
只保留 `conf > 阈值`（如 0.5）的框。低阈值找到更多物体但引入误报——第 03 课的精确率/召回率权衡，现在用在检测上。

## 6. NMS（非极大值抑制）
相邻单元对同一物体都触发，产生重复框。NMS：保留最高分的框，删除所有与它重叠超过 IoU 阈值的低分框，重复。

## 7. AP / mAP
按置信度排序预测，每个与一个真实框匹配（IoU ≥ 阈值），构建精确率-召回率曲线。曲线下面积是 **AP**；在 IoU 阈值 0.5–0.95 上平均得到 **mAP**。`eval.py` 实现了它。

## 运行
```
python boxes.py     # 框 / IoU / 网格运算
python demo.py      # 完整流程：阈值 -> NMS -> AP -> 图片
```
