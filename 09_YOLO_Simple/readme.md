## 核心概念
**检测损失**——训练网格来输出框和置信度。640×640 图像下采样到 20×20 特征图。每个单元预测 `(tx, ty, tw, th, conf)`；圆心所在单元是唯一的正样本单元。

损失有两部分：
- **坐标损失**（MSE）：框有多不准。只作用于正样本单元。
- **置信度损失**（加权 BCE）：这个单元里有没有物体？400 个单元里约 1 个正样本，正样本权重 3.0，负样本权重 0.5，这样大量空背景不会主导。

框编码与第 08 课一致：
- `tx, ty`：相对于单元**中心**的偏移，解码 `sigmoid(raw)·2 − 0.5`，然后 `cx = (gx + 0.5 + tx)/S·size`；
- `tw, th`：`sigmoid(raw)` × 图像尺寸。

## 模型
六个步长 2 的卷积块（640→320→160→80→40→20）加一个 1×1 检测头。全程卷积 + BatchNorm + LeakyReLU。总共约 158 万参数。

## 与第 08 课的区别
没有新数学——`utils.py` 里的 IoU/NMS/AP 代码原样复用。唯一的新东西是 `forward_loss`（MSE + 加权 BCE）和训练循环。

## 运行
```
python dataset_generator.py   # 12800 训练 + 3200 验证合成圆
python train.py               # 约 120 轮，每 10 轮报告 AP
python test.py                # 在 test_result/ 里画框
```
