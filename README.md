# NoobTorch 1.0（中文版）
面向新手的 **PyTorch 实战教程**，适合零基础的人、调参爱好者以及所有觉得 **AI** 很酷的人。
- 简单
- 精简
- *极度友好*

本课程欢迎：
- 新手
- 跟风玩家
- 调参侠
- 因各种原因无法参加专业 ML 课程的人

所需知识：
- 数学：高中水平 + `∂x/∂y`（偏导数）
- 编程：能读懂 Python
- 有 `数据结构与算法` 基础更佳

与传统 PyTorch 课程不同，NoobTorch 提供简单的 **双击即运行** 代码和 **直观** 的讲解，帮助初学者尽快开始用 PyTorch 开发深度学习模型。
*至少你不会再害怕它*
*论文也不再像一堆乱码*

本课程**不**试图教你一切。深度学习发展太快，任何一门课程都无法覆盖全部。它给你的是习惯和基础：读代码、理解原理、跑起来看结果。学完之后，新的论文、新的网络结构、新的损失函数，都只是又一章，而不是一堵翻不过去的墙。你不会学完就什么都懂；你学会的是**如何自己学剩下的部分**。

## 环境搭建（一次性）
```bash
pip install -r requirements.txt
```
然后**双击你想运行的 `.py` 文件**（在对应课程文件夹里）——不需要终端、不需要 `cd`、不需要命令行参数。每个脚本会自动找到自己的文件夹和共享的 `data/` 目录。MNIST/CIFAR 首次运行时会自动下载到 `data/`。

## 检测任务背景图（COCO）
第 09、10、10x 课会在真实 COCO 照片上画合成圆，让网络学会忽略杂乱背景。图片**不包含**在本仓库中——请自行下载（CC BY 4.0 协议；请注明 COCO 数据集来源）。

1. 下载任意 COCO 图片子集（只要原始 `.jpg`，**不要**标注 JSON）：
   - **val2017.zip** — 约 1 GB，5,000 张图（推荐）
   - test2017.zip — 约 6.6 GB，4 万张图
   - train2017.zip — 约 19 GB，11.8 万张图

   下载页面：https://cocodataset.org/#download
   直链：      http://images.cocodataset.org/zips/val2017.zip

2. 解压后把 `.jpg` 文件**平铺**复制到 `assets/backgrounds/`（不要放在 `val2017/` 子文件夹里）。生成器也支持在课程目录下放一个 `background/` 文件夹。

3. 按顺序双击以下文件生成检测数据集：
   - `09_YOLO_Simple/dataset_generator.py`
   - `10_YOLO_DSC/dataset_generator.py`
   - `10x_Lab_CoordConv_YOLO/dataset_generator.py`

   然后双击每节课里的 `train.py`。对于 07x/10x CoordConv 实验课，双击 `train.py` 跑对照组，双击 `train_coords.py` 跑实验组（10x 课还对应 `test.py` / `test_coords.py`）。

## 从 `n00b` 到 `1337`

| 课次 | 主题 | 你将学到什么 |
|--------|-------|---------------------|
| 00 | Hello PyTorch | 新手工具包：张量、`autograd`、`.backward()`、保存/加载 |
| 01 | MNIST 全连接网络 | 全连接网络，你的第一个能训练的模型 |
| 02 | MNIST CNN | 卷积就是滑动窗口；池化；Dropout |
| 03 | 验证与过拟合 | 训练/验证/测试集划分，学习曲线，精确率/召回率 |
| 04 | 训练旋钮 | 数据增强、余弦学习率、权重衰减——一次调一个旋钮 |
| 05 | CIFAR + BatchNorm | 三通道数据，加深网络，批量归一化 |
| 06 | CIFAR ResNet18 | 残差连接是聪明的捷径 |
| 07 | 迁移学习 | 预训练骨干网络，微调，在你自己的图片上推理 |
| 07x | 实验：CoordConv | 做对照实验，测量，做判断 *（选学）* |
| 08 | 检测入门 | 边界框、IoU、网格、置信度、NMS、mAP（不训练） |
| 09 | 简易 YOLO | 网格检测器 + 坐标/置信度损失 |
| 10 | YOLO 深度可分离卷积 | 深度可分离卷积，更小更快的网络 |
| 10x | 实验：CoordConv 检测器 | 同一个实验，这次用在检测上 *（选学）* |
