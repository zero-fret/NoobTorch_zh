# 04 — 训练旋钮
第 03 课给了我们尺子（验证准确率）。现在学习让模型泛化和加速收敛的四个杠杆。

## 核心概念
**一次只调一个旋钮，在验证集上衡量。** 旋钮作为 `train.py` 顶部的开关：

```python
USE_AUGMENTATION = True
USE_SCHEDULER = True
USE_WEIGHT_DECAY = True
ACTIVATION = 'leaky_relu'
```

## 四个旋钮

### 1. 数据增强——"免费数据"
`RandomAffine` 每轮对每张图做轻微旋转/平移/缩放。模型看到同一数字在新姿势下，必须学习*不变*特征。增强后的运行通常获得更高的**测试**准确率，即使训练损失收敛更慢。

### 2. 学习率调度——余弦退火
固定学习率是一种折中：早期大步长帮助逃离差的局部极小；晚期小步长让你稳定下来。`CosineAnnealingLR` 在 `T_max` 轮内按余弦曲线从 `LR` 平滑衰减到 ~0。它不提高上限；它用更少的轮次达到上限。

### 3. 权重衰减——L2 惩罚
`weight_decay` 在损失中加上 `λ·Σw²`，温和地把每个权重拉向零。大权重让模型记住噪声；小权重让决策边界平滑。这是与 Dropout/数据增强并列的第二个经典正则化方法。

### 4. 激活函数——LeakyReLU vs ReLU
ReLU 神经元如果一直接收强负梯度可能永久变成零（"死亡神经元"）。`LeakyReLU(0.01)` 对负数保留一个小斜率，梯度可以继续流动。代价：可忽略。

### 额外收获：DataLoader 不是免费的
`num_workers=N` 在 GPU 训练时用子进程预加载/增强接下来的 N 个批次，`pin_memory=True` 加速 CPU→GPU 传输。在简单任务（MNIST）上，加载器可能是瓶颈；设为 CPU 核心数左右。

## 与第 03 课的区别
循环没有新东西——只有 `train.py` 的配置变了。模型是第 02 课的 CNN，激活函数可切换。
