# 03 — 它真的在学习吗？（验证、过拟合、指标）
在相信任何准确率数字之前，你需要一个诚实的评估协议。

## 核心概念
将数据分成三个互不相交的集合：

| 集合 | 用途 | 触碰频率 |
|---|---|---|
| **训练** | 更新参数 | 每轮 |
| **验证** | 选择超参数 / 发现过拟合 | 每轮，绝不用于训练 |
| **测试** | 唯一的最终数字 | 最后一次 |

在你的评估集上训练就像**开卷考试**：背答案的模型考 100 分但什么也没学到。

## 三条曲线看懂过拟合
把训练损失和验证损失按轮次画出来，你就能判断当前状态：

- **欠拟合**：训练和验证损失都很高且仍在下降 → 训练更久或用更大的模型。
- **健康**：两者都下降，然后在接近的位置平稳。
- **过拟合**：训练损失持续下降（→ ~0），但验证损失停止改善并开始**上升**。网络在死记训练图像。

这个脚本故意让过拟合很容易出现：一个大的 `OverfitNet` 只在 `TRAIN_SUBSET = 2000` 张图上训练。打开 `results.png` 看两条线分叉。

## 超越准确率
单一准确率掩盖了*哪些*类别失败了。
- **混淆矩阵** `cm[真实, 预测]`：对角线 = 正确；非对角线 = 错误。
- **精确率** = 我预测的里面有多少是对的（`TP/(TP+FP)`）。
- **召回率** = 存在的里面我找到了多少（`TP/(TP+FN)`）。
- **F1** = 两者的调和平均。

## 如何调参（协议）
1. 改一个旋钮（轮数、学习率、宽度、数据增强……）；
2. 训练，比较**验证**指标；
3. 保留更好的那个；
4. 只有调参完成后，才报告一次**测试**结果。

## 运行
```
python train.py
```
你会看到每轮表格、保存的 `results.png`、测试准确率、宏平均 P/R/F1，以及最容易混淆的数字对。

## 练习（做这些——这就是课程本身）
- 设 `TRAIN_SUBSET = 2000`，然后 `50000`；比较训练和验证之间的差距。
- 设 `EPOCHS = 15` 然后 `60`；找到验证损失开始上升的那一轮。
- 把模型宽度减半（`OverfitNet(hidden=32)`）；还会过拟合吗？
- 用一个笔记本记录改动和验证结果——这就是调参的真实工作方式。
