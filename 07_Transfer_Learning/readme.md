# 07 — 迁移学习与推理
从零训练一个大网络需要数百万张标注图片。几乎没人这么做。

## 核心概念
**迁移学习**：拿一个在大数据集（如 ImageNet，120 万张图）上训练好的骨干网络，复用它的低/中层特征（边缘、纹理、部件）。两种常见做法：

1. **特征提取（train.py）**：冻结骨干网络（`requires_grad=False`），把最后的分类器换成针对你类别新的层，只训练那一层。几分钟，便宜，小数据上也能用。
2. **微调（finetune.py）**：加载冻结头部的权重，保持低层入口 + layer1/layer2 冻结，但解冻 layer3/layer4 和头部。用*小的*骨干学习率（2e-4）对比大的头部学习率（1e-3），让预训练特征被适配而不是被摧毁。这就是迁移学习超越从零训练的地方。

## 保存 / 加载
- `torch.save(model.state_dict(), 'xxxx.pth')` 只保存学到的张量。
- 重建相同的网络结构，然后 `model.load_state_dict(torch.load(...))`。
- 用 `weights_only=True` 加载，除非文件确实包含非张量数据（安全默认值）。

## 与第 06 课的区别
我们根本不定义网络——直接实例化 `torchvision` 的 ResNet18 并下载权重，只动它的 `fc` 层。这也是为什么推理是单独的脚本：保存一个你永远不用的模型没有意义。

## 运行
```
python train.py          # 冻结头部：下载预训练权重，训练头部，保存 .pth
python finetune.py       # 解冻高层，微调 -> cifar10_resnet18_finetuned.pth
python inference.py                      # 分类第一张 CIFAR 测试图
python inference.py --image my_photo.jpg # 分类你自己的图片
```

CIFAR-10 结果（RTX 4050）：冻结头部 **80.01%**，微调后 **95.77%**
（对比第 06 课从零训练 ResNet18 的 92.78%）。
