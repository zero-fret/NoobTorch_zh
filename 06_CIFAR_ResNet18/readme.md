# 06 — CIFAR ResNet18
残差连接让网络可以变深而不退化。

## 核心概念
深层普通网络在层数增加时可能在训练集上也变得*更差*——不只是过拟合，而是优化失败（梯度消失、退化）。**残差块**把输入直接加到其层的输出上：

```
out = ReLU( W2·ReLU(W1·x) + x )
```

块只需要学习*差值*（残差）。如果多余的层没用，它们学零，块就表现为恒等映射，所以深度不会有害——梯度通过直线 `+ x` 短路流到前面的层。这就是让数百层网络可训练的"聪明旁路"。

## 模型
- CIFAR 入口：一个 3×3 步长 1 的卷积（32×32 图像太小，不适合 ImageNet 的 7×7 步长 2 入口）。
- 四个阶段，每阶段 2 个块，通道 `64 → 128 → 256 → 512`，每阶段第一个块步长为 2。
- 全局平均池化 → 10 类线性层。
- 维度变化时短路路径用 `1×1` 卷积匹配。

## 训练配方（标准 CIFAR 配方）
- **SGD + 动量 0.9**，`lr=0.1`（动量和 BatchNorm 让大学习率安全快速），
- `weight_decay=5e-4`，
- 余弦退火，
- **强数据增强**：RandAugment（2 个随机操作）+ 水平翻转 + 填充裁剪 + RandomErasing。

## 与第 05 课的区别
新的块结构（跳跃连接）；其他一切——BatchNorm、增强、调度器、fit 循环——都复用。

## 运行
```
python model.py     # 打印输出形状和参数量
python train.py
```
预期：25 轮后测试准确率 ~90–93%（更多轮次会更高）。
