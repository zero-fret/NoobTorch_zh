# 10x — 实验 B：CoordConv 对检测有帮助吗？（选学）
与实验 A 相同的对照实验，但这次在目标检测器上。

## 实验
`utils.py` 和 `dataset_generator.py` 与第 10 课逐字节相同。模型是第 10 课的网络加一个开关：

```bash
python train.py            # 对照组：与第 10 课相同
python train.py --coords   # 实验组：输入加 2 个坐标通道
```

开关是唯一的变量；其他一切（种子、轮数、学习率、损失、数据、阈值）都固定。

### 如何保持对比公平
加两个输入通道会改变第一个卷积的形状，否则两个模型会从不同权重开始。`train.py` 先用固定种子构建对照组模型，然后把共享权重复制到实验组，**只将两个新增的坐标通道零初始化**。第 0 步时两个网络完全相同；坐标通道是唯一区别，因此是干净的单变量实验。

## 假设
检测预测的是**位置**，所以显式坐标可能比在分类上更有帮助。但卷积检测器本来就是为定位设计的，额外通道可能帮助不大或偏向物体通常出现的位置。**测一下。**

## 协议
1. 双击一次 `dataset_generator.py`（共享数据）。
2. 双击 `train.py`（对照组），然后 `test.py`。记录 AP。
3. 双击 `train_coords.py`（实验组），然后 `test_coords.py`。权重保存为 `model_coords_False.pth` / `model_coords_True.pth`。
4. 在相信差异之前用 2-3 个种子重复两者。

| 组别 | coords | AP@0.5 | mAP@0.5:0.95 | 参数量 |
|---|---|---|---|---|
| 对照组 | False | 72.77% | 35.51% | 726,213 |
| CoordConv 组 | True | 73.09% | 35.90% | 726,501 |

（单种子，RTX 4050。坐标在这里给出 +0.3/+0.4 个百分点的小优势——方向上与 CoordConv 论文一致，即坐标对依赖坐标的任务有帮助，但差距在种子噪声范围内。在认为是真实效应之前跑 2-3 个种子。）

（提示：参数量在入口只增加了 288——额外成本微不足道。）
