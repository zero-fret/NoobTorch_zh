# 00 — Hello PyTorch
在第一个可训练网络之前你需要掌握的最少知识：**张量**和**自动微分**。

## 核心概念
**张量**是一个数组（0 维标量、1 维向量、2 维矩阵、3 维 RGB 图像……），可以在 GPU 上运行，并记住用于构建它的操作。如果 `requires_grad=True`，调用 `.backward()` 会将每个张量的 `.grad` 填充为其导数——不需要手动求导。

```python
x = torch.tensor([2.0], requires_grad=True)
y = x ** 2 + 3 * x + 1
y.backward()      # x.grad = dy/dx = 2*x + 3
```

本节课建立三个习惯：
- 梯度会**累积**，所以每步之前要清零（`x.grad.zero_()`，后面用 `optimizer.zero_grad()`）；
- 需要梯度的张量必须是**浮点数**；
- 尾部下划线 `_` 表示**原地操作**（`zero_`、`add_`、`copy_`）。

## 术语表（参考——不用背，需要时回来查）
- **模型 / 网络**：一个有很多参数的函数。
- **层**：对数据的一次变换（如 `nn.Linear`、`nn.Conv2d`）。
- **激活函数**：非线性函数（如 ReLU `max(x, 0)`）；没有它，深层网络就只是一个线性变换。
- **前向传播**：从输入计算预测。
- **损失函数**：一个数字，表示预测错得多离谱。
- **反向传播**：通过链式法则计算每个参数对损失的梯度。
- **优化器**：用梯度来更新参数（如 Adam、SGD）。
- **学习率**：优化器的步长。
- **批次 / 轮次**：批次 = 一次权重更新前处理的样本数；轮次 = 完整遍历一遍数据。
- **DataLoader**：按模型期望的形状喂入批次。
- **训练 / 验证 / 测试**：训练调整参数；验证用于调参；测试只用一次。
