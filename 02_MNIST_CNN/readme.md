# 02 — MNIST CNN
卷积就是一个滑动的小窗口。

## 核心概念
全连接层把图像拉平成一个长向量，破坏了空间结构——数字移动两个像素就变成了不同输入。**卷积**在图像上滑动一个小卷积核；同一组权重遍历每个位置，所以：
- 参数量取决于卷积核大小和通道数，**不**取决于图像大小；
- 局部模式（边缘、角点）无论出现在哪里都能被检测到；
- 更深的层把局部模式组合成全局形状。

```
输入 (1×28×28)
  卷积 1→12, 3×3, pad=1 → ReLU → 最大池化 2×2   (12×14×14)
  卷积 12→24, 3×3, pad=1 → ReLU → 最大池化 2×2  (24×7×7)
  展平 → FC 1176→70 → ReLU → Dropout(0.25) → FC 70→10
```

## 两个附带概念
- **最大池化**在每个 2×2 区域保留最强激活。它将空间尺寸减半，扩大感受野，并增加一点平移不变性。没有可学习参数。
- **Dropout** 在训练时（`model.train()`）随机将一部分激活置零，迫使网络不依赖任何单个神经元。它是一种廉价的正则化；在 `eval()` 时自动关闭。

随着层数加深，空间尺寸缩小而通道数增加：你在用"位置"换"内容"。
