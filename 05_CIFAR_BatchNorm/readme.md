# 05 — CIFAR-10 + BatchNorm
更难的数据（三通道彩色照片，10 个类别）和更深的网络。

## 核心概念
堆叠层时，每层的输入分布会随着前面权重的变化而不断漂移——这就是*内部协变量偏移*，它让深度网络缓慢且不稳定。

**BatchNorm2d** 在当前小批次上对每个通道做归一化（均值 ~0，方差 ~1），然后施加可学习的缩放 γ 和偏移 β。效果：
- 训练快得多，可以用更高的学习率；
- 轻度正则化（批次统计量增加了噪声）；
- 通常不需要 Dropout。

它需要合理的批次大小（≥ 8），在 `train()` 和 `eval()` 下行为不同——这正是 `model.eval()` 重要的原因。

## 网络结构
三个相同的 卷积→卷积→池化 块（`32 → 64 → 128` 通道，空间尺寸 `32 → 16 → 8 → 4`），然后接全连接头。BatchNorm 是唯一的理念变化；卷积还是第 02 课的操作。

## 运行实验
`train.py` 暴露一个开关：
```python
USE_BN = True   # 设为 False -> BatchNorm 变成 nn.Identity，网络不变
```
先用 `True` 跑，再用 `False` 跑。关闭 BatchNorm 后训练开始更慢，深层变得挑剔。这是你第一次能*感受到*为什么 BatchNorm 让 100+ 层网络变得可行。

## 读取激活健康度
脚本打印每个 ReLU 后的激活均值/标准差/死亡（零）单元比例：
- 标准差趋近 0 → 信号消失；
- 死亡比例接近 1 → 神经元死亡（见第 04 课的 LeakyReLU）；
- 有 BatchNorm 时这些数字在所有深度下都保持良好尺度。

## 与第 04 课的区别
同样的增强/优化器旋钮；模型只是更深，每个卷积后接 `BatchNorm`，并新增了诊断钩子。

## 运行
```
python train.py
```
预期：有 BN 时测试准确率 88% 左右，没有时更慢更低。
