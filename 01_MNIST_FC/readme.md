# 01 — MNIST 全连接网络（你的第一个能用的网络）
用全连接网络分类手写数字（MNIST）。

## 核心概念
**训练循环**——每个模型永远使用的五个步骤：
```
清零梯度 → 前向传播 → 计算损失 → 反向传播 → 优化器更新
```

## 模型
```
输入 (784) → FC1 (128) → ReLU → FC2 (64) → ReLU → FC3 (10) → 10 个 logit
```
- **FC / 全连接**：每个输入连接到每个输出。
- **Logit**：softmax 之前的原始分数；`CrossEntropyLoss` 内部已包含 softmax。
- 参数量：`784·128 + 128 + 128·64 + 64 + 64·10 + 10 = 109,194`（约 0.44 MB float32）。

## 与第 00 课的区别
不再是对玩具公式求导，而是对数以千计参数的损失求导，让优化器更新它们。`train.py` 让整个循环**可见**——在这里读一遍；后面的课程复用 `common/engine.py`。

## 运行

```
python train.py
```
