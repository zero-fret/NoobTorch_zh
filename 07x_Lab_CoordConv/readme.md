# 07x — 实验 A：CoordConv 真的有用吗？（选学）
课程不再是"相信教程说的"。这是一个对照实验。

## 想法
**CoordConv** 在输入上拼接两个额外通道，告诉每个像素它的 X/Y 位置（归一化到 [-1, 1]）。这给了网络显式的位置先验——当位置重要时有用（比如目标总出现在固定位置）。

但卷积的设计就是*平移不变*的：同一个数字在移动后的位置应该还是同一个数字。加坐标破坏了这个不变性。所以在 MNIST 上，CoordConv 很可能没用甚至有害。**让数据来决定，不是论文。**

## 实验设置
每次只改一个变量，其他一切保持相同（种子、增强、调度器、轮数、结构）：

| 组别 | `USE_COORDS` | `ACTIVATION` | 验证准确率 | 测试准确率 |
|---|---|---|---|---|
| 1（对照） | False | relu | | |
| 2 | False | leaky_relu | | |
| 3（CoordConv） | True | relu | | |
| 4（CoordConv） | True | leaky_relu | | |

## 要注意什么
- **在噪声范围内（±0.1%）**：在这个数据集上没有效果——这是一个有效且常见的结果。
- **加坐标后训练/验证差距变大**：如预期那样，它过拟合到位置上。
- **相信差异之前用种子 1、2、3 重复**——单次幸运的运行证明不了什么。

## 这节课教什么
"让它跑起来"之后最有价值的技能：**提出假设 → 改一个变量 → 测量 → 重复**。对一个数据集有用的技巧可能伤害另一个数据集。
